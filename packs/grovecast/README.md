# GroveCast

Streamer lower-third for GTA San Andreas 1.0.

CLEO writes `CLEO\GroveLink\cast.ini`. Local page on **8099** is an OBS Browser Source.

Not a Twitch bits phone and not a chaos pack.

## In game

- **F3** flips the live slate flag.
- Leaves **K** (phone), **F4** (AW FPS), **F6** (switcher) alone.

## OBS

1. Tick GroveCast in SA Modkit, Install.
2. Run `START_CAST.bat`.
3. OBS Browser Source: `http://127.0.0.1:8099/obs` — 1280×200 — Transparent.
